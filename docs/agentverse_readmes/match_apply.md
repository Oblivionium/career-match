# Match & Apply

Scores jobs against a candidate profile with an explainable 0-100 score (skills, role fit,
level fit, freshness) and lists missing skills. Also writes tailored Application Packs:
cover letter, role-specific resume bullets, and a skill-gap plan.
Part of the CareerMatch multi-agent system.

**Inputs:** `MatchRequest`, `PackRequest`  **Outputs:** `MatchResults`, `PackResult`

Keywords: job matching, skill gap analysis, cover letter, resume tailoring, careers
