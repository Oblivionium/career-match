# Demo script (target 2.5 minutes)

Record in ASI:One with the agents running on an always-on machine. Rehearse twice.

1. **0:00–0:15 Problem.** "Students send 100 applications blind. They don't know which roles
   fit them or why they keep getting rejected."
2. **0:15–0:35 Resume in.** Paste the strong sample resume. Show the skills it found and the
   form card. Fill: role, city, Internship.
3. **0:35–1:00 Live matches.** Carousel of real listings with match %. Point out the line that
   one source was down (run with `SIMULATE_SOURCE_FAILURE=adzuna`) and results still came back.
4. **1:00–1:25 Honest detail.** Open the top job: matched skills, missing skills, apply link.
5. **1:25–2:05 Paid action.** Get Application Pack → review card → testnet FET payment →
   verified on-chain → cover letter, bullets, gap plan arrive.
6. **2:05–2:20 Weak resume.** Paste the weak resume: it still finds realistic matches and is
   honest about the gaps.
7. **2:20–2:30 Close.** Architecture slide (4 agents), monetization line, "running on Agentverse now."

Then share the same ASI:One chat to get the public shared chat URL for Devpost.

Sample resumes: `tests/fixtures.py` (`RESUME_STRONG`, `RESUME_WEAK`). Use your own if you
prefer, but avoid real personal details in a public video.
